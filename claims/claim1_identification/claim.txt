CLAIM 1 — NLACP Identification
==============================

Claim
-----
CHAGent's identification module accurately distinguishes Natural Language Access Control Requirements (NLACPs) from non-NLACP sentences across the evaluation document folds (t2p, acre, ibm, collected, cyber, and the combined "overall" set) outperforming current state of the art.

Maps to
-------
Paper Section/Table: <FILL IN — e.g., "Table X: NLACP identification results">.

What run.sh does
----------------
Evaluates the PROVIDED identification checkpoint for each document fold using
artifact/identification/evaluate_classification.py. One checkpoint per dataset
(single seed) is expected at:
    artifact/checkpoints/id/<fold>/checkpoint
(No training is performed; this reproduces the reported test-set metrics.)
Note: evaluate_classification.py's checkpoint path has NO seed level
(id/<fold>/checkpoint), so a single seed per dataset is sufficient.

Metrics reported (per fold)
---------------------------
accuracy, precision, recall, F1  (printed as a Python dict).

Reproducibility note
--------------------
A single representative seed is shipped for identification; this checkpoint
faithfully reproduces that seed's reported single-seed results. Obtaining the
full multi-seed mean/SD is a simple extension: bert-base-uncased is lightweight
and the training script + data are included, so train extra seeds with the
command run.sh prints and evaluate them the same way.

Prerequisites
-------------
- ../install.sh has been run and the venv is active.
- HuggingFace access configured (HF_TOKEN or `huggingface-cli login`) so
  bert-base-uncased can be downloaded.
- Identification checkpoints present at artifact/checkpoints/id/<fold>/checkpoint.

  Identification checkpoints are published inside the SAME chagent-artifacts
  repo (https://huggingface.co/chagent-artifacts/chagent-identification), and ../download_checkpoints.sh links them to
  artifact/checkpoints/id/<fold>/checkpoint automatically. If they are not yet
  uploaded (or a fold is missing), run.sh prints the train command
  (bert-base-uncased is small and trains quickly) and skips that fold rather
  than evaluating a non-existent model.

See expected/expected_output.txt for the output format and where to compare the
numbers against the paper.
