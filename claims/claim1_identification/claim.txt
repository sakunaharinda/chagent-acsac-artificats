CLAIM 1 — NLACP Identification
==============================

Claim
-----
CHAGent's identification module accurately distinguishes Natural Language Access Control Requirements (NLACPs) from non-NLACP sentences across the evaluation document folds (t2p, acre, ibm, collected, cyber, and the combined "overall" set) outperforming current state of the art.

Maps to
-------
Paper Section/Table: <FILL IN — e.g., "Table X: NLACP identification results">.

What run.sh does
----------------
Evaluates the PROVIDED identification checkpoint (seed 0) for each document fold
using artifact/identification/evaluate_classification.py. One checkpoint per
fold is expected at:
    artifact/checkpoints/id/<fold>/checkpoint
(No training is performed; this reproduces the reported test-set metrics.)
Note: evaluate_classification.py's checkpoint path has NO seed level
(id/<fold>/checkpoint), so a single seed per fold is sufficient.

Metrics reported (per fold)
---------------------------
accuracy, precision, recall, F1  (printed as a Python dict). The seed-0 output
for every fold is included as reference in eval_logs/<fold>_0.txt, and the
numbers are tabulated in expected/expected_output.txt.

Reproducibility note
--------------------
A single seed (0) is shipped for identification; these checkpoints faithfully
reproduce that seed's reported single-seed results.
Obtaining the full multi-seed mean/SD is a simple extension: bert-base-uncased
is lightweight and the training script + data are included, so train extra seeds
with the command run.sh prints and evaluate them the same way.

Prerequisites
-------------
- ../install.sh has been run and the venv is active.
- HuggingFace access configured (HF_TOKEN or `huggingface-cli login`) so
  bert-base-uncased can be downloaded.
- Identification checkpoints present at artifact/checkpoints/id/<fold>/checkpoint.

  These are published (seed 0, per fold) at
  https://huggingface.co/chagent-artifacts/chagent-identification with layout
  <fold>/0/<model files>, and ../download_checkpoints.sh links each to
  artifact/checkpoints/id/<fold>/checkpoint automatically. If a fold's checkpoint
  is missing, run.sh prints the train command (bert-base-uncased is small and
  trains quickly) and skips that fold rather than evaluating a non-existent model.

See expected/expected_output.txt for the output format and the per-fold reference
numbers to compare against.
