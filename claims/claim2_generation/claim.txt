CLAIM 2 — Access Control Policy Generation (DSARCP), end-to-end CHAGent
=======================================================================

Claim
-----
CHAGent generates correct Access Control Policies (decision, subject, action, resource, condition, purpose — the "DSARCP" setting) from NLACPs. The full pipeline outperforms the current state-of-the-art in terms of the policy component extraction and ACR-generation F1 reported in the paper across datasets.

-------
Paper Section/Table: <FILL IN — e.g., "Table Y: DSARCP generation results">.

What run.sh does
----------------
Runs artifact/generation/evaluation/eval_chagent.py with retrieval + refinement
enabled (the default CHAGent configuration), using the PROVIDED checkpoints (no
training). Each run prints its metrics and writes generations under
<RESULT_DIR>/<mode>/.

On start, run.sh asks which scope to run:
  [D] Default    — all datasets, seed 3 only (6 runs, ~5 hours on an A100).
                   Reproduces the seed-3 point estimates; matches the seed-3
                   logs in eval_logs/.
  [E] Everything — all datasets, seeds 2, 3, 4 (18 runs, ~13-15 hours). Needed
                   only for the full three-seed mean/SD reported in the paper.
Pressing Enter selects the Default. The prompt is skipped when SEEDS (or
DATASETS) is preset in the environment, and a non-interactive shell falls back
to the Default automatically.

Time cost of [E]: the full pipeline averages ~49 min per (dataset, seed),
ranging from ~19 min (ibm) to ~118 min (acre; ~6 h across three seeds), so the
whole sweep is ~13-15 h of GPU time. Measured per-dataset/seed times are in
infrastructure/README.txt.

IMPORTANT — run protocol:
  * The Default scope runs the full pipeline for one seed (seed 3) and prints
    that seed's F1 directly.
  * The paper reports the mean/SD over three seeds (2, 3, 4). To produce all
    three, run scope [E]; the MEAN and STANDARD DEVIATION are then computed
    EXTERNALLY (not by this script) by collecting the per-seed F1 values.

Metrics reported (per dataset, per seed)
----------------------------------------
  Results (SARCP):          Precision, Recall, F1, plus component-wise F1.
  Results (ACR Generation): Precision, Recall, F1.

Prerequisites
-------------
- venv active (../install.sh), HuggingFace access configured, GPU available.
- Checkpoints downloaded and arranged by ../download_checkpoints.sh, which
  fetches them from https://huggingface.co/chagent-artifacts and creates:
      artifact/generation/checkpoints/<mode>_act_<seed>/checkpoint   (generators)
      artifact/generation/checkpoints/verification/checkpoint        (verifier)
  The Hub stores generators nested as <mode>_act/<seed>/checkpoint; the helper
  renames them to the flat <mode>_act_<seed> path eval_chagent.py expects.
  The verifier is required here because refinement (--refine) is enabled.

Seeds
-----
The three seeds are 2, 3, 4 (matching the checkpoint directories on the Hub).
The Default scope runs seed 3 only; scope [E] runs all three. To target specific
cells, preset the environment, e.g.  DATASETS=ibm SEEDS=3 ./run.sh
